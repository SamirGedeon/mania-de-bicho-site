# Mania de Bicho — prompts de imagens

## Como usar

Cada bloco abaixo está pronto para copiar integralmente: o mesmo prompt base aparece repetido em todas as 16 fotos para manter consistência. Gere **um arquivo por bloco**, sem montar colagens ou páginas. As dimensões são alvos de exportação; se o gerador não aceitar o tamanho, use a proporção mais próxima e recorte sem deformar o assunto. Para PNG transparente, pedir transparência real e conferir canal alfa.

A geração livre reproduz direção e composição, mas não garante um animal idêntico ao da referência. Para máxima fidelidade, forneça a foto correspondente como **alvo de edição**, usando as instruções de preservação ao final deste documento. Os HEX orientam a fotografia; cores exatas de UI devem ser aplicadas no CSS.
